Case Comp Deck Designer

Builds, critiques and learns from case-competition decks. It follows a case comp playbook and a pattern library distilled from nine reference decks.

Use it
  1. Copy the skill with the button above.
  2. Paste it into a chat with Claude and ask it to save it as a skill.
  3. Attach your case and ask for a deck.

Prompts to try once it is saved

  • Build a 6-slide submission deck for this case. The problem statement and judging criteria are attached.
  • Critique my draft deck against the rubric and give me the top fixes.
  • Learn from these decks and update the pattern library. The second one won its competition.

Built from one 51-slide playbook session and nine reference decks (134 slides). The library holds layout and structure patterns only, not any team's analysis or numbers.
